# 3D 미니게임 모음

Godot 4.7 3D 미니게임 8종: 2048, 수박 게임, 뱀파이어 서바이버, 플래피 버드, 탄막 슈팅, 테트리스, 지렁이, 지뢰찾기.

## 웹에서 하기

https://supark0403.github.io/3d-land-odyssey/ (GitHub Actions 자동 배포)

## 직접 실행

- Windows: [Releases](https://github.com/supark0403/3d-land-odyssey/releases) 에서 `3d-land-odyssey.exe` 다운로드 (단일 파일)
- 에디터: Godot 4.7.2로 `project.godot` 열기 → F5

## 조작

- 2048: 방향키/ADWS, R 재시작
- 수박: WASD 이동, 클릭/스페이스 낙하
- 서바이버: WASD 이동(자동 공격), 1/2/3 강화
- 플래피: 스페이스 상승, A/D 좌우
- 슈팅: WASD 이동(자동 발사)
- 테트리스: 방향키 이동, Q/E/W/S/A/D 회전, Space 하드드랍, C 홀드
- 지렁이: WASD/방향키
- 지뢰찾기: 좌클릭 열기, 우클릭 깃발

공통: P 일시정지, R 재시작, 설정에서 모바일 모드(터치 버튼).
