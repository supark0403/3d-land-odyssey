# 3D Mini Games

Godot 4.7 3D 미니게임 10종: 2048, Suika, Survivor, Flight, Tetris, Shooter, Breakout, Snake, Minesweeper, Stack.

## 웹에서 하기

https://supark0403.github.io/3d-land-odyssey/

## 직접 실행

- Windows: [Releases](https://github.com/supark0403/3d-land-odyssey/releases) 에서 `3d-land-odyssey.exe` 다운로드 (단일 파일)
- Android: `3d-land-odyssey.apk` 다운로드 후 설치 (출처 불명 허용 필요)
- macOS: `3d-land-odyssey-macos.zip` 압축 해제 후 `3d 2048.app` 실행 (첫 실행은 우클릭 → 열기)
- 에디터: Godot 4.7.2로 `project.godot` 열기 → F5

## 조작

- 2048: 방향키 상하좌우 + W안쪽 S바깥쪽
- Suika: WASD 이동, 클릭/스페이스 낙하
- Survivor: WASD/조이스틱 이동(자동 공격), 1/2/3 강화, 스테이지별 테마 변경
- Flight: WASD 상하좌우, 노란 공 30개 수집 타임어택
- Shooter: WASD 이동(자동 발사)
- Tetris: 방향키 이동, Q/E/Yaw, W/S/A/D 기울기, Space 하드드랍, C 홀드
- Breakout: A/D 좌우 + W/S 상하 패들, 앞벽 게이트 실점, 시간 경과 멀티볼
- Snake: 화면 기준 조향 + Space/C 고도, 9³ 큐브
- Minesweeper: 좌클릭 열기, 우클릭/깃발 모드 깃발
- Stack: 스페이스/클릭으로 낙하 블록 쌓기

공통: P 일시정지, R 재시작(서바이버 제외), 설정에서 게임별 키 변경 가능, Score에서 게임별 최고 기록 열람, 모바일 모드(가상 조이스틱/터치 버튼).
